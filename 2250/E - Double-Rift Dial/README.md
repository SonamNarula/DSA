<div class="header"><div class="title">E. Double-Rift Dial</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p> </p><p>A permutation $$$p_1,p_2,\ldots,p_n$$$ is written clockwise on a circular dial.</p><p>Choose a starting position $$$s$$$ and read one full circle clockwise, beginning with $$$p_s$$$. The $$$k$$$-th number read is</p><p>$$$$$$ p_{((s+k-2)\bmod n)+1} $$$$$$</p><p>For any nonempty prefix of this process, let $$$S$$$ be the set of numbers already read. Regard the elements of $$$S$$$ as points on the number line and split $$$S$$$ into maximal segments of consecutive integers. We call these segments the blocks of $$$S$$$.</p><p>For example, $$$S=\{1,2,5,7,8,9\}$$$ has $$$3$$$ blocks: $$$\{1,2\}$$$, $$$\{5\}$$$, and $$$\{7,8,9\}$$$.</p><p>A starting position $$$s$$$ is called <span class="tex-font-style-it">good</span> if the set for every nonempty prefix has at most $$$2$$$ blocks.</p><p>Find the number of good starting positions.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. It is guaranteed that $$$p$$$ is a permutation.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$2\cdot 10^5$$$.</p></div><div class="output-specification"><div
